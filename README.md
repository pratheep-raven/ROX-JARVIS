# ROX JARVIS

ROX JARVIS is a Windows voice-controlled AI desktop assistant.

It combines a fast local command router with a downloaded
Hugging Face Qwen3-1.7B GGUF model for complex natural-language tasks.

## Features

- Clap-based activation
- Voice command recognition
- Spoken assistant responses
- Fast command routing
- Local Hugging Face AI planning
- Windows application control
- Browser and Google search control
- File and folder management
- Keyboard and mouse automation
- Battery, CPU, RAM and storage information
- Safety confirmation for sensitive actions

## AI Model

- Repository: ggml-org/Qwen3-1.7B-GGUF
- Model file: Qwen3-1.7B-Q4_K_M.gguf
- Runtime: llama-cpp-python
- Execution: Local CPU
- API key: Not required
